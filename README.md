# Lambda_CDM

This repository is a model file system for the Lambda CDM cosmological model (the standard Big Bang framework with dark energy and cold dark matter), packaged for use with physics-IDE educational workflows.

## Purpose

The project is intended to help new users explore how large physics models are assembled and tested, including where assumptions, limits, and inconsistencies may appear.

## Included theory scope

Conventional theories included in this model package:
- Lambda CDM cosmology
- General Relativity (Einstein)
- Quantum Field Theory
- The Particle Physics Standard Model (including Higgs-field mass generation context)

Archaic or historical theories are also expected to be represented so users can compare predictions and identify where they fail against evidence.

## Educational testing use-cases

The model is structured so users can run and compare tests across multiple scales, such as:
- Galaxy redshift behavior and expansion predictions
- Cross-checks between cosmology and particle physics assumptions
- Conceptual tests around Higgs-field explanations of particle mass

This repository is therefore positioned as an educational comparison environment, not just a single-theory reference.
